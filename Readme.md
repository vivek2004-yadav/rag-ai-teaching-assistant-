# RAG AI Teaching Assistant

A production-ready **Retrieval-Augmented Generation (RAG)** system designed to index educational video playlists into a persistent **ChromaDB Vector Database**. Users can ask questions in natural language and receive grounded answers complete with exact video titles and precise timestamp citations.

---

## 🌟 Key Features

* **Speech-to-Text Processing:** Converts raw video and audio lecture files into timestamped JSON transcriptions using OpenAI Whisper.
* **Semantic Paragraph Merging:** Merges tiny 2-second speech fragments into 45-to-60 second rich paragraph chunks, eliminating context fragmentation and improving vector retrieval precision.
* **Persistent ChromaDB Vector Store:** Stores 3072-dimensional vector embeddings generated by Google Gemini API (`gemini-embedding-001`) in a local persistent ChromaDB instance (`./chroma_db`) with HNSW cosine distance indexing.
* **Incremental & Resilient Indexing:** Checks existing video metadata in ChromaDB before embedding, automatically skipping already-indexed videos and handling API rate limits gracefully with exponential backoff retries.
* **Grounded Answer Generation:** Performs top-K (10 nearest neighbors) cosine similarity retrieval to inject accurate context into Google Gemini LLM (`gemini-2.5-flash`), eliminating AI hallucinations.
* **Interactive CLI Interface:** Allows users to query the vector index interactively from the terminal.

---

## 🛠️ Tech Stack

* **Language:** Python 3.9+
* **Vector Database:** ChromaDB (`chromadb`) with HNSW Cosine Indexing
* **Speech Recognition:** OpenAI Whisper (`whisper`)
* **LLM & Embeddings:** Google Gemini REST API (`gemini-2.5-flash` & `gemini-embedding-001`)
* **Environment Configuration:** `python-dotenv`
* **Data Format:** JSON / SQLite (`chroma.sqlite3`)
