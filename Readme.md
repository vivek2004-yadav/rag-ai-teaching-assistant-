# 🤖 Agentic RAG AI Teaching Assistant

> **📌 What This Project Does:**
> This project is an intelligent **AI Teaching Assistant** for video-based courses (such as web development video playlists). It processes raw lecture videos by extracting audio, transcribing speech into timestamped transcripts using OpenAI Whisper, and indexing vector embeddings in ChromaDB. When a student asks any question, an autonomous **LangGraph ReAct AI Agent** searches the lecture vector database and provides detailed, accurate answers—complete with the exact video title, episode number, and start-to-end timestamp citations where the topic is taught.

A state-of-the-art **Agentic Retrieval-Augmented Generation (RAG)** system built with **LangChain**, **LangGraph**, **Google Gemini**, **ChromaDB**, and **OpenAI Whisper**.

---

## 🌟 Key Features

* **End-to-End Data Pipeline:** 
  * **Video-to-Audio:** Extracts `.mp3` audio from lecture videos using FFmpeg (`video_to_mp3.py`).
  * **Speech-to-Text Transcription:** Transcribes audio into timestamped JSON subtitles using OpenAI Whisper (`large-v2`) (`mp3_to_json.py`).
* **LangChain Text Chunking:** Uses `RecursiveCharacterTextSplitter` (`chunk_size=1000`, `chunk_overlap=200`) to group short subtitle fragments into rich passage chunks while preserving metadata (`title`, `number`, `start`, `end` timestamps).
* **Persistent Vector Database:** Indexes 3072-dimensional vector embeddings generated by Google Gemini API (`gemini-embedding-001`) in a persistent **ChromaDB** vector store (`./chroma_db`).
* **LangGraph Agentic Architecture:** Employs a stateful **ReAct Agent** (`create_react_agent`) powered by **Google Gemini 2.5 Flash** (`gemini-2.5-flash`) that dynamically invokes the `retriever_tool` when external course knowledge is required.
* **Conversational Checkpointer Memory:** Manages state history across queries using LangGraph `InMemorySaver` memory.
* **Grounded Answers with Source Citations:** Guarantees factual responses with direct video title references and start/end timestamp citations.

## 🛠️ Tech Stack

* **Frameworks:** LangChain, LangGraph
* **Language Model (LLM):** Google Gemini 2.5 Flash (`gemini-2.5-flash`)
* **Embedding Model:** Google Gemini Embedding (`gemini-embedding-001`)
* **Vector Database:** ChromaDB (`chromadb`)
* **Speech Recognition (ASR):** OpenAI Whisper (`whisper` `large-v2`)
* **Media Processing:** FFmpeg
* **Language & Runtime:** Python 3.9+
* **Environment Management:** `python-dotenv`

## 🚀 Getting Started

### 1. Environment Setup
Create a `.env` file in the project root directory and add your Google Gemini API Key:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```
*(or `pip install langchain langchain-core langchain-community langchain-google-genai langgraph chromadb python-dotenv`)*

### 3. Run the Agentic RAG AI Teaching Assistant
To start asking questions interactively:
```bash
python3 process_incoming.py
```

### 4. (Optional) Preprocess New Transcripts
To batch-index new video transcripts into ChromaDB:
```bash
python3 preprocess_json.py
```
