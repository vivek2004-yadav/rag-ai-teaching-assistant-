# RAG AI Teaching Assistant

A state-of-the-art **Retrieval-Augmented Generation (RAG)** system built with **LangChain (LCEL)**, **Google Gemini**, **ChromaDB**, and **OpenAI Whisper**.

This system indexes course video lectures into a persistent vector store and runs a deterministic **RAG Retrieval Pipeline** using LangChain Expression Language (LCEL) that retrieves relevant lecture passages and answers student questions with precise video titles, video numbers, and exact start/end timestamp citations.

---

## 🌟 Key Features

* **End-to-End Data Pipeline:**
  * **Video-to-Audio:** Extracts `.mp3` audio from lecture videos using FFmpeg (`video_to_mp3.py`).
  * **Speech-to-Text Transcription:** Transcribes audio into timestamped JSON subtitles using OpenAI Whisper (`large-v2`) (`mp3_to_json.py`).
* **LangChain Text Chunking:** Uses `RecursiveCharacterTextSplitter` (`chunk_size=1000`, `chunk_overlap=200`) to group short transcript fragments into rich passage chunks while preserving metadata (`title`, `number`, `start`, `end` timestamps).
* **Persistent Vector Database:** Indexes vector embeddings generated by Google Gemini API (`gemini-embedding-001`) in a persistent **ChromaDB** vector store (`./chroma_db`).
* **LCEL RAG Pipeline:** Built with **LangChain Expression Language (LCEL)** powered by **Google Gemini 2.5 Flash** (`gemini-2.5-flash`) for efficient, deterministic retrieval and answer synthesis.
* **Grounded Answers with Source Citations:** Guarantees factual responses with direct video title references and start/end timestamp citations.

---

## 🛠️ Tech Stack

* **Frameworks:** LangChain (LCEL)
* **Language Model (LLM):** Google Gemini 2.5 Flash (`gemini-2.5-flash`)
* **Embedding Model:** Google Gemini Embedding (`gemini-embedding-001`)
* **Vector Database:** ChromaDB (`chromadb`)
* **Speech Recognition (ASR):** OpenAI Whisper (`whisper` `large-v2`)
* **Media Processing:** FFmpeg
* **Language & Runtime:** Python 3.9+
* **Environment Management:** `python-dotenv`

## 🚀 Getting Started

### 1. Environment Setup
Create a `.env` file in the project root directory and add your Google Gemini API Key:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```
*(or `pip install langchain langchain-core langchain-community langchain-google-genai chromadb python-dotenv`)*

### 3. Run the RAG AI Teaching Assistant
To start asking questions interactively:
```bash
python3 process_incoming.py
```

### 4. (Optional) Preprocess New Transcripts
To batch-index new video transcripts into ChromaDB:
```bash
python3 preprocess_json.py
```
